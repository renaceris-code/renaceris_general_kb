Cambios implementados:

Día 01/09
* Reportes: el nombre del profesional ahora se muestra según su perfil. Los médicos aparecen como “Dr.” y los especialistas estéticos como “Esp. Estético”. Esto también se refleja en las exportaciones.
* Procedimientos estéticos: un especialista estético puede iniciar más de un procedimiento a la vez. Antes de hacerlo, el sistema muestra una confirmación con el paciente y el servicio que ya tiene en curso.

Día 02/09
* Panel del especialista: el aviso de procedimientos pendientes ahora muestra todos los procedimientos que siguen en curso, con el paciente, servicio y una acción individual para concluir cada uno.
* Historia clínica: al programar una consulta se puede ver y actualizar la historia clínica del paciente. El campo se oculta cuando no corresponde a una consulta para evitar guardar información innecesaria.

Día 03/09
* Perfil del paciente: la historia clínica siempre es visible, incluso cuando todavía no tiene número asignado, y se puede editar desde el perfil.
* Validación de historia clínica: el sistema ya reconoce cuando se intenta usar un número de historia clínica repetido y muestra un aviso claro. Se dejó preparada la validación de base de datos para evitar duplicados de historia clínica y DNI.

Cambios pendientes:

* Consultas virtuales: habilitar por servicio la opción de consulta virtual, mostrarla al programar una consulta compatible y distinguir las citas virtuales de las presenciales en las tarjetas de citas.
